rclone-backup

プライバシーポリシー

本ポリシーは、個人用バックアップツール rclone-backup と、この説明用ウェブサイトに適用します。

利用対象と目的

本ツールは、管理者本人が管理するデータを、本人が許可した Google Drive に保存し、消失時に復元する目的で使用します。一般向けのサービスや第三者向けのアカウント接続機能は提供していません。

アクセスする情報

  • バックアップ対象のローカルデータには、アプリの設定、会話履歴、関連文書などが含まれます。
  • Google Drive API を通じて、バックアップのファイル名、ファイルID、サイズ、更新日時などの情報と、確認・復元に必要なバックアップファイルの内容を扱います。
  • 継続的なバックアップのため、OAuth のアクセストークンと更新トークンをバックアップ実行端末で保持します。Google アカウントのパスワードを本ツールが収集することはありません。

要求する権限と利用範囲

現在の Google Drive アクセス権限は、ファイルの参照・作成・編集・削除を許可するものです。権限はバックアップフォルダだけに制限されていません。本ツールでは、バックアップファイルの保存・更新・一覧確認・取得と、管理者が行うバックアップ管理に使用します。

保存先と保持期間

バックアップは、管理者が許可した Google Drive 内に保存します。作成や検証に必要な一時コピーを実行端末に置く場合があります。日次バックアップは最新ファイルを上書きし、週次バックアップは世代別に保持します。すべての世代に共通する自動削除期限は設けておらず、不要なバックアップは管理者が削除します。

認証トークンは端末のアクセス権を制限した設定ファイルで管理します。この説明サイトには、認証トークンやバックアップ内容を保存しません。

提供先と利用しない目的

バックアップ保存のために Google Drive へデータを送信します。本ツールによる Google API データの広告利用、販売、汎用AI・機械学習モデルの学習目的での利用は行いません。また、そのような目的で第三者へ提供しません。本ツールによるバックアップ処理と、バックアップ対象となる各アプリの通常動作は別です。

アクセスの解除と削除

管理者は、Google アカウントの接続管理画面から rclone-backup のアクセスを解除できます。解除後は本ツールによる新たなアクセスができなくなりますが、既存のバックアップが自動的に削除されるわけではありません。

データを削除する場合は、Google Drive 内のバックアップを削除し、必要に応じてゴミ箱も空にします。実行端末の一時コピーと認証設定も管理者が削除します。

説明サイトのアクセス情報

このサイトには、アクセス解析タグ、広告、ログインフォームを設置していません。配信基盤である GitHub Pages では、サービス運用上アクセス情報が処理される場合があります。詳細は GitHub のプライバシーステートメントをご覧ください。

Google API ユーザーデータポリシー

Google API から受領した情報の利用および他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policyに従います。

連絡先と変更

本ポリシーに関する連絡は、説明ページ用リポジトリの Issuesをご利用ください。個人情報や認証情報は投稿しないでください。運用変更に伴い本ポリシーを更新する場合は、このページと更新日を変更します。
